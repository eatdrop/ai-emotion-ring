# Repository structure

- `apps/admin-console`: Vue-based administration console.
- `services/api-server`: Flask API and authentication service.
- `ml`: algorithm and model evaluation boundary.
- `firmware`: BLE and embedded integration boundary.
- `data`: schemas, synthetic samples, and governance notes.
- `docs`: product, architecture, and competition documentation.
- `scripts`: local API and LAN test helpers.

The public repository excludes runtime data, logs, signing keys, dependency caches, and environment secrets.
